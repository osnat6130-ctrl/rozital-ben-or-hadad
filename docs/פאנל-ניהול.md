# פאנל הניהול - מה מוכן ומה צריך ממך

## מה כבר עובד

- **כניסה** ב-`/admin` עם שם משתמש וסיסמה. שתי משתמשות (אוסנת ורוזיטל), כל אחת עם סיסמה משלה.
- **עריכה על האתר החי**: אחרי כניסה מופיע סרגל בתחתית המסך. לוחצים "מצב עריכה", ואז על כל כותרת, פסקה, נקודה או כפתור - ועורכים במקום. Enter מסיים, Escape מבטל.
- **שמירה ופרסום**: כל שמירה יוצרת רשומה בהיסטוריה עם תיאור בעברית ("עדכון 2 טקסטים: הורים וילדים (כותרת העל, כותרת ה-Hero)"), עם השם של מי שערכה. האתר מתעדכן תוך כדקה.
- **הגנה מדריסה**: אם שתיכן עורכות במקביל, השנייה תקבל הודעה במקום לדרוס.

## מה עוד לא

- **תמונות וסרטונים** - עדיין לא ניתנים להחלפה מהפאנל (שלב הבא).
- **מסך היסטוריה ושחזור** בתוך הפאנל - כרגע ההיסטוריה קיימת בגיטהאב, אבל בלי מסך ייעודי.
- **טשטוש פנים אוטומטי** בתמונות שמעלים - צריך להמשיך לטשטש לפני ההעלאה.

## מה צריך ממך כדי להעלות לאוויר

### 1. סיסמאות

בטרמינל, פעם לכל משתמשת:

```bash
node scripts/hash-password.mjs osnat "אוסנת"
```

```bash
node scripts/hash-password.mjs rozital "רוזיטל"
```

כל הרצה מבקשת סיסמה ומדפיסה רשומת JSON. הסיסמה עצמה לא נשמרת בשום מקום.

### 2. טוקן גיטהאב

ב-github.com: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**

- Repository access: **Only select repositories** → `rozital-ben-or-hadad`
- Permissions → Repository permissions → **Contents: Read and write** (זו ההרשאה היחידה שצריך)
- Expiration: לבחור תאריך ולרשום תזכורת לחדש

### 3. פרויקט ב-Vercel

לחבר את הריפו `osnat6130-ctrl/rozital-ben-or-hadad`. Vercel יזהה Vite לבד.

ב-**Settings → Environment Variables** להוסיף:

| שם | ערך |
|---|---|
| `SESSION_SECRET` | מחרוזת אקראית - להריץ: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` |
| `ADMIN_USERS` | `[` + שתי הרשומות משלב 1, מופרדות בפסיק + `]` |
| `GITHUB_TOKEN` | הטוקן משלב 2 |
| `GITHUB_REPO` | `osnat6130-ctrl/rozital-ben-or-hadad` |
| `GITHUB_BRANCH` | `main` |

### 4. אחרי שהאתר באוויר ב-Vercel

- לבדוק שהכל תקין בכתובת של Vercel
- לעדכן את הדומיין בקבצים: `src/content/site.json` (השדה `url`), `index.html`, `public/robots.txt`, `public/sitemap.xml`
- לכבות את GitHub Pages, ואז אפשר למחוק את `.github/workflows/deploy.yml` ואת `public/404.html`

## פיתוח מקומי

צריך `.env.local` (להעתיק מ-`.env.example`), ואז שני טרמינלים:

```bash
npm run dev
```

```bash
npm run dev:api
```

מומלץ להגדיר `GITHUB_BRANCH` לענף בדיקה ולא ל-`main`, כדי שבדיקות לא ישנו את האתר החי.
